# TR-YÖS Zone · Bootcamp

Личный кабинет учеников школы TR-YÖS Zone: bootcamp.tryoszone.com.

- вход: логин и пароль, Google, Telegram;
- ID ученика открывает курсы, расписание, баллы и уровень доступа;
- отсчёт до экзамена, ближайшее занятие, прогресс по задачам;
- админка (/admin): ученики, ID, группы, индивидуальные занятия, расписание, доступ, баллы,
  назначение доп. занятий и тестирований — всем, выбранным группам или отдельным ученикам.

## Тренажёр

Банк задач лежит в `content/` (только сервер, в браузер не уходит):
`bank-v2-practice-*.json`, `bank-v3-practice-*.json` — тренажёр, работа над ошибками, выживание;
`bank-v2-iq-*`, `bank-v2-algebra-*`, `bank-v2-geometry-*`, `bank-v3-exam-*` — пробники;
`bank-retired.json` — задачи и темы, снятые с выдачи (их нет на экзамене или они слишком лёгкие).
Задачи пробников не встречаются в тренажёре, поэтому вариант нельзя выучить.

Этот банк — единственный источник задач и для сайта tryoszone.com: задача дня
и быстрый пробный тест берут задачи через открытое API `/api/bank/…`
(`lib/public-bank.ts`). Наружу отдаются только задачи тренажёра.

| Режим | Адрес | Что делает |
|---|---|---|
| Пробники | `/exam` | 80/100, 40/50, 20/25, только логика, только математика. Вариант хранится в базе, перезагрузка не сбивает таймер |
| Тренажёр | `/trainer` | все темы экзамена по трём разделам, разбор сразу |
| Работа над ошибками | `/mistakes` | задачи, где последний ответ был неверным |
| Выживание | `/survival` | серия без конца, три жизни, таблица лидеров |

Балл 0–500 считается той же формулой, что и быстрый тест на сайте:
100 + точность логики · 180 + точность математики · 220, ошибка стоит
четверти верного ответа. Пробник из одного раздела растягивает свой вес
на всю шкалу, поэтому баллы разных форматов сравнимы.

Полные форматы пробников открываются уровнем доступа `exams` в админке;
быстрая диагностика на 20 задач доступна всем вошедшим.

## Переменные окружения

| Переменная | Откуда |
|---|---|
| `DATABASE_URL` | появляется сама, когда к проекту подключена база Neon (Vercel → Storage) |
| `BOOTCAMP_ADMINS` | администраторы через запятую: логин, почта Google или @ник в Telegram |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | Google Cloud → OAuth client; redirect: `https://bootcamp.tryoszone.com/api/auth/google/callback` |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_NAME` | бот школы; в BotFather: `/setdomain` → bootcamp.tryoszone.com |
| `AUTH_SECRET` | необязательно: ключ подписи сессий (по умолчанию выводится из `DATABASE_URL`) |

Таблицы в базе создаются сами при первом запросе.
